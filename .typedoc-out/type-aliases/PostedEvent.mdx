> **PostedEvent**\<`Protocol`, `EventName`\> = `Protocol` *extends* `undefined` ? `string` : `EventName` *extends* keyof [`State`](../interfaces/State.mdx)\<`any`, `any`\> ? `never` : `EventName`

Valid first argument to [Base.post](../interfaces/Base.mdx#post) / [State.postNow](../interfaces/State.mdx#postnow) — a protocol key that names
a **void** handler (event), excluding reserved [State](../interfaces/State.mdx) method names.

## Type Parameters

### Protocol

`Protocol` *extends* \{ \} \| `undefined`

Machine vocabulary interface, or `undefined` for untyped `string` mode

### EventName

`EventName` *extends* keyof `Protocol`

Member key being constrained

## Remarks

Collisions with `keyof State` become `never`, preventing `post('transition', …)` at compile time.
