# Reference manual

The canonical reference lives in the repository as [`docs/REFERENCE.md`](https://github.com/filasieno/ihsm/blob/master/docs/REFERENCE.md).

Topics covered:

- Key concepts and static typing with `Protocol`
- Messaging: `post`, `call`, `sync`, `deferredPost`, `postNow`
- Transitions, entry/exit, guards, `then()` pseudo-states
- `restore()`, error model, tracing levels
- `makeHsm` factory and zero production dependencies

For API details, generate TypeDoc locally with `npm run doc:api` or browse the tutorials — each page runs
the real runtime in your browser.
