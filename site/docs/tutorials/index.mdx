# Interactive tutorials

Each tutorial embeds a live ihsm actor in the browser. Use the **Sender** and **Message** selectors to
choose what to dispatch, edit payload fields, then **Send**. The **Trace** panel shows the verbose dispatch
log (read-only). **Reset** rebuilds the machine from its initial configuration.

All tutorials are also verified by Mocha specs:

```bash
npm run test:tutorials
# or: nix flake check
```
