# ihsm

An idiomatic hierarchical state machine package for TypeScript.

Use the **interactive tutorials** to run state machines in your browser: pick a sender, choose a message,
fill in any payload fields, send events, and read the live dispatch trace. Every tutorial also has a
matching Mocha spec under `tutorials/*/tutorial.spec.ts`.

## Quick start

```bash
nix develop
nix flake check          # build + unit/tutorial tests
npm run doc:preview      # Docusaurus dev server
```
