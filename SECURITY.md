# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.0.19+ | yes       |
| < 0.0.19 | no       |

## Reporting a vulnerability

Please report security issues **privately** via [GitHub Security Advisories](https://github.com/filasieno/ihsm/security/advisories/new).

Do not open public issues for security reports.

We aim to acknowledge reports within a few business days.
