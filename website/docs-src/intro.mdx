# ihsm

An idiomatic hierarchical state machine package for TypeScript.

This site is the **single documentation hub**: the [reference manual](/reference) and
[interactive tutorials](/tutorials) live here — one sidebar, one search index, one build.

## Quick start

```bash
nix develop
nix flake check          # build + unit/tutorial tests
npm run doc:preview      # Docusaurus dev server
```
