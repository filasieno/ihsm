# Tutorials

Each tutorial is a documentation page with prose, code, and an embedded **playground** where you run
the state machine in the browser: pick a **Sender** and **Message**, edit payload fields, **Send**, and
read the live **Trace**. **Reset** rebuilds the machine from its initial configuration.

All tutorials are verified by Mocha specs:

```bash
npm run test:tutorials
# or: nix flake check
```
