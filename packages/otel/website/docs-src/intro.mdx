# @ihsm/otel

**OpenTelemetry integration for [ihsm](https://github.com/filasieno/ihsm)** — turn an actor's
dispatch into traces and logs, built on ihsm's native, vendor-neutral instrumentation seam.

<div className="badge-row">
  <span className="badge">Optional add-on</span>
  <span className="badge">Callback-driven</span>
  <span className="badge">Zero core coupling</span>
  <span className="badge">Deterministic & replayable</span>
</div>

## The model in one line

> **One macrostep = one trace.** Every external stimulus that drives an actor to stability produces
> exactly one trace; each microstep (event dispatch) is a span; `hsm.log.*` records become
> trace-correlated logs.

`ihsm` emits neutral signals — `onMacrostepBegin`, `onMicrostepBegin`, `onError`, `onLog`, … — and
`@ihsm/otel` maps them to OpenTelemetry. Nothing about OTEL lives in the `ihsm` core: the
integration is **opt-in** and driven entirely by the `Instrumentation` callback interface. If you
never install this package, ihsm has no OpenTelemetry footprint.
