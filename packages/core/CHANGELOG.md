# Changelog

All notable changes to `@ihsm/core` are documented in this file.

## [0.1.21] - 2026-06-20

### Added

- **`actor.id`** on all actor shells and handler `hsm` (alias of `actorUuid`).

## [0.1.20] - 2026-06-20

### Changed

- Lockstep semver with `ihsm@0.1.20` and `@ihsm/otel@0.1.20`.

## [0.1.2] - 2026-06-20

### Added

- First public npm release — scoped re-export of `ihsm`, `@ihsm/core/testing`, and `@ihsm/core/transition-routines`.
- Pins runtime dependency `ihsm@0.1.2` (same semver as this package).
