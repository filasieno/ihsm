Standard JavaScript random-generation surface exposed by [Port](../classes/Port.mdx) and mocked by
[testing!TestPort](../../testing/classes/TestPort.mdx).

Route every nondeterministic draw through the machine's port — never `Math.random()` or
`crypto.*` directly in handlers — so tests can script values with
[feedRandom](../../testing/classes/TestPort.mdx#feedrandom) / [feedCryptoRandom](../../testing/classes/TestPort.mdx#feedcryptorandom) /
[feedUUID](../../testing/classes/TestPort.mdx#feeduuid) / [feedRandomBytes](../../testing/classes/TestPort.mdx#feedrandombytes).
