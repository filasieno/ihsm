> **InboundPoster**\<`Context`, `InternalProtocol`\> = [`Base`](../interfaces/Base.mdx)\<`Context`, `InternalProtocol`\>

Restricted handle a [Port](../classes/Port.mdx) uses to post **internal** events back into its machine.

It is the [Base](../interfaces/Base.mdx) surface narrowed to the `InternalProtocol`, so a port can only
`post` the events it is allowed to raise — never public commands.
