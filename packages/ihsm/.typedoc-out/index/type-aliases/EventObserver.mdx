> **EventObserver** = (`message`) => `void`

Observer invoked for **every** event posted through a [testing!TestActor](../../testing/type-aliases/TestActor.mdx).

Registered via [testing!TestActor](../../testing/type-aliases/TestActor.mdx) `subscribe` — a capability unique to the test surface.
Wire it to [testing!TestPort.record](../../testing/classes/TestPort.mdx#record) to build a golden trace on the port under test.

## Parameters

### message

[`TracedMessage`](../interfaces/TracedMessage.mdx)

## Returns

`void`
