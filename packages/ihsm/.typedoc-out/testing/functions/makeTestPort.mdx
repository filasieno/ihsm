> **makeTestPort**\<`P`\>(`PortClass`): [`Mock`](../type-aliases/Mock.mdx)\<`P`, `P` *extends* `object` ? `T` : `never`\>

Instantiate an `@`[mock](mock.mdx)-decorated mock class — the canonical way to build a test port.

Pass the mock **class**; you get back a typed instance whose abstract port methods (inferred from
the machine's [TopState](../../index/classes/TopState.mdx)) are scriptable [Stubbed](../interfaces/Stubbed.mdx) methods, ready for
`port.method.default(...)`. The port's `actor` is still bound lazily when you hand the instance to
[makeActor](../../index/functions/makeActor.mdx) / [makeTestActor](makeTestActor.mdx).

## Type Parameters

### P

`P` *extends* [`TestPort`](../classes/TestPort.mdx)\<[`Any`](../../index/type-aliases/Any.mdx)\>

The mock class instance type (a [TestPort](../classes/TestPort.mdx) subclass)

## Parameters

### PortClass

() => `P`

The `@mock`-decorated mock class

## Returns

[`Mock`](../type-aliases/Mock.mdx)\<`P`, `P` *extends* `object` ? `T` : `never`\>

A scriptable [Mock](../type-aliases/Mock.mdx) instance

## Throws

If `PortClass` was not decorated with `@`[mock](mock.mdx)

## Example

```ts
const port = ihsmTest.makeTestPort(WatcherMock);
port.watch.default(() => ({ value: 1, subscription: { dispose: () => port.send('onClosed') } }));
const sm = ihsmTest.makeTestActor(WatcherTop, new WatcherCtx(), port);
```
