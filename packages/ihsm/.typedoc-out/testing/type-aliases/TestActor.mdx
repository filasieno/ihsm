> **TestActor**\<`Context`, `Protocol`, `InternalProtocol`, `P`\> = [`Hsm`](../../index/interfaces/Hsm.mdx)\<`Context`, [`Dispatch`](../../index/type-aliases/Dispatch.mdx)\<`Protocol`, `InternalProtocol`\>\> & `object`

Full-access view returned by [makeTestActor](../functions/makeTestActor.mdx) for **deterministic testing**.

Exposes the merged [Dispatch](../../index/type-aliases/Dispatch.mdx) protocol — so a test can drive internal events
(`onSpawn`, `onExit`, …) directly without a live port — **plus** typed access to the
machine's `port` for asserting outbound calls or pushing observations.

## Type Declaration

### port

> `readonly` **port**: `P`

### subscribe()

> **subscribe**(`observer`): [`Disposable`](../../index/interfaces/Disposable.mdx)

Observe **every** event as it is posted through this machine — a capability unique to the
test surface (it is intentionally absent from [Actor](../../index/type-aliases/Actor.mdx) / [Hsm](../../index/interfaces/Hsm.mdx)).

The observer fires synchronously at post time with the event name and payload, capturing
client posts, handler self-posts, and port-driven internal events alike. Wire it to
[TestPort.record](../classes/TestPort.mdx#record) when you want a golden trace on the port under test.
