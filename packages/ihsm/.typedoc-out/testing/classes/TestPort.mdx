Standard JavaScript random-generation surface exposed by [Port](../../index/classes/Port.mdx) and mocked by
testing!TestPort.

Route every nondeterministic draw through the machine's port — never `Math.random()` or
`crypto.*` directly in handlers — so tests can script values with
[feedRandom](#feedrandom) / [feedCryptoRandom](#feedcryptorandom) /
[feedUUID](#feeduuid) / [feedRandomBytes](#feedrandombytes).

### send()

> **send**\<`EventName`\>(`eventName`, ...`payload`): `void`

Post an internal event inward through the bound [actor](../../index/classes/BasePort.mdx#actor).

This is the one channel a port (or a test driving the port) uses to feed the machine its
internal protocol. Because emission is explicit — never a side effect of the outbound call
the machine made — a single mock works across many tests: the test decides *when* (and
whether) to push each internal event.

#### Type Parameters

##### EventName

`EventName` *extends* `string` \| `number` \| `symbol`

##### eventName

##### payload

### advance()

> **advance**(`millis`): `void`

Advance the virtual clock by `millis`, firing every timer whose deadline is reached, in
deadline order. Timers scheduled by a fired callback within the same window are **not** run
until a later `advance` — mirroring how a deferred re-schedule lands on the next run-to-completion turn.

#### Parameters

##### millis

`number`

Virtual milliseconds to advance (negative values are clamped to `0`)

#### Returns

`void`
