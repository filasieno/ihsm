# ihsm

**Class-based hierarchical state machines and run-to-completion actors for TypeScript** — typed `post`/`call`, zero production dependencies.

This site has two sections: the **[Reference](/reference)** (concepts, semantics, and interactive examples on one page) and the **[API reference](/api)** (TSDoc from `src/index.ts`).

## Quick start

```bash
npm install ihsm
```

See [Key concepts](/reference#_1-key-concepts) on the Reference page for your first `makeHsm` actor.
